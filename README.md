# 歡樂釣魚大冒險 🎣

專為 **4 歲小朋友** 設計的網頁體感釣魚遊戲，靈感來自大型電玩場的《釣魚魂》機台！免安裝、免閱讀文字，支援平板、手機觸控、電腦滑鼠/鍵盤與手機體感甩竿。

## 特色亮點
- **超大觸控與多重操作**：點水面（或向上滑動）就能拋竿；魚咬鉤後可以**畫圈轉動超大捲線器**、**連點螢幕/捲線器**、**按空白鍵**，或開啟右上角 📱 **體感模式**甩動手機來拋竿與收線！
- **大型機台必殺技 ⚡**：能量集滿時按下發光的「⚡ 閃電！」大按鈕，施放彩虹閃電把大魚電暈拉上來！
- **高互動海底世界**：點泡泡會「啵！」破掉、點河豚會鼓成大氣球、點海底小螃蟹會開心跳舞！
- **驚喜事件**：定時出現「🐳 彩虹大鯨魚」大魔王與「🌈 彩虹派對時間」雙倍星星獎勵。
- **友善無挫折設計**：魚線不會斷裂，搭配歡樂電玩音效、震動回饋與中文語音鼓勵（「哇！釣到小丑魚了！好棒喔！」）。
- **我的海洋圖鑑 🐠**：收錄 12 種可愛海洋生物，點選已收集的魚還會發出聲音介紹自己。

## 本地啟動方式
直接用瀏覽器開啟 `index.html`，或在專案目錄啟動本地伺服器：

```bash
python3 -m http.server 8080
```

接著用瀏覽器開啟 `http://localhost:8080` 即可開始遊玩！
