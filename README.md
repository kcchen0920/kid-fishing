# 歡樂釣魚大冒險 🎣

專為 **4 歲小朋友** 設計的網頁體感釣魚遊戲，靈感來自大型電玩場的《釣魚魂》機台！支援平板、手機觸控、電腦滑鼠/鍵盤、手機體感甩竿，並可加入主畫面全螢幕遊玩（PWA）。

## 線上遊玩（GitHub Pages）
https://kcchen0920.github.io/kid-fishing/

## 特色亮點
- **零閱讀視覺引導與超大按鈕**：水面動態波紋靶心＋右下角超大「🎣 拋竿！」發光按鈕，點水面、向上滑或按按鈕都能輕鬆拋竿。
- **體感捲線器加速特效**：畫圈轉動（或連點／空白鍵／搖晃手機）收線時，捲線器光環會依速度從 **藍 → 綠 → 金 → 彩虹** 升級並噴出星光火花！
- **大型機台拔河進度條**：魚兒圖示會隨收線往水桶移動，掙扎時晃動冒汗 💦，被閃電電暈時變成 💫。
- **圓形光環 ⚡ 閃電必殺技**：集滿 100% 時外圈發光並語音提醒「閃電集滿了！快按閃電！」。
- **小小釣魚王成長與釣竿升級**：隨星星累積自動升級稱號（🫧 泡泡新手 → 🐠 小魚達人 → 🐢 海龜夥伴 → 🦈 鯊魚騎士 → 👑 海洋大王），並自動換上更酷的釣竿外觀與更強收線力道！
- **今日魚籃與連釣獎勵**：頂部直接顯示最近釣到的可愛魚兒、連釣 Combo 獎勵，以及滿條時全螢幕霓虹邊框的「🌈 彩虹派對 x2 星星！」與「🐳 彩虹大鯨魚」事件。
- **4 歲防誤觸家長設定**：右上角 `⚙️` 需長按 1 秒才會開啟（獨立控制音效、語音、體感甩竿與重置進度），避免孩子玩得太激動誤按靜音。

## 本地啟動方式
直接用瀏覽器開啟 `index.html`，或在專案目錄啟動本地伺服器：

```bash
python3 -m http.server 8080
```

接著用瀏覽器開啟 `http://localhost:8080` 即可開始遊玩！
